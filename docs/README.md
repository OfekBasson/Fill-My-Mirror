# Personal website

Static personal/researcher website for Ofek Basson (`index.html` + `style.css`, no build step).

To publish with GitHub Pages: repo **Settings → Pages → Source**, select the `main` branch
(or the branch this lives on) and the `/docs` folder, then save.

Update the "Paper" and "Project Page" links in `index.html` (currently marked "coming soon")
once the Fill My Mirror paper is public and the project page is live.
